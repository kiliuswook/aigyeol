# 내 아이의 MBTI · 전체 기획서

- 최종 수정일: 2026-11-15
- 버전: 웹 시제품(별도 버전 번호 없음, `main` 브랜치 = 배포본)
- 구현 파일: `index.html` 한 파일(HTML, CSS, JS). 그림은 `assets/`, 손그림 UI 조각은 `assets/ui/`

## 1. 개요

만 2~7세 아이의 타고난 기질을 MBTI처럼 네 글자로 읽는 부모용 영유아 기질검사 웹앱이다.
부모(또는 양육자)가 최근 한 달간 아이의 모습을 떠올리며 답한다.
결과는 양육 참고용이며 의학적 진단이나 발달 평가를 대신하지 않는다. 화면 문구도 진단처럼 쓰지 않는다.

정밀 리포트는 두 갈래로 나뉜다.

- **기질 결과**: 타고난 성향. 4축, 세부 기질 12가지, 네 글자 유형과 별명
- **성격 결과(자라는 힘)**: 경험으로 자라는 힘. 끈기, 스스로 힘, 함께 힘

화면 기준은 휴대폰 세로 화면 한 줄 배치(본문 최대 폭 480px)이다. 아트는 색연필·크레용 손그림 콘셉트(C4)다.

## 2. 검사 구성

| 항목 | 무료 간이검사 | 유료 정밀검사 |
|---|---|---|
| 문항 | 12문항(축당 3, 세부 기질당 1) | 66문항 = 기질 48 + 자라는 힘 18 |
| 시간 | 약 1분 | 약 10분. 간이검사 응답은 이어받아 54문항만 추가 |
| 결과 | 네 글자 유형, 별명, 가장 뚜렷한 축 1개 풀이 | 정밀 리포트(기질 탭 + 성격 탭). [결과 화면 세부 기획서](content/report.md) |

- 응답: 5점 척도(전혀 아니다 ~ 매우 그렇다) + '잘 모르겠다'. 문항마다 장면 예시를 함께 보여 준다.
- 기질 4축(문항 데이터 `index.html` 의 `AX`): 탐험·관찰(E/I), 섬세·무던(S/N), 표현·잔잔(F/T), 리듬·자유(J/P). 축마다 세부 기질 3개, 세부 기질마다 4문항.
- 자라는 힘(문항 데이터 `GR`): 끈기, 스스로 힘, 함께 힘. 척도마다 6문항.
- 16유형 별명은 `NICK`, 유형 풀이 문구는 `P`, 문항 예시는 `EXS` 에 있다.

### 채점 규칙

- 응답 1~5점. 역채점 문항은 6에서 뺀다.
- '잘 모르겠다'는 점수에 넣지 않는다. 같은 세부 기질의 나머지 문항으로 계산한다. 간이검사에서는 같은 세부 기질의 다른 문항을 대신 묻는다. 한 세부 기질 문항을 모두 모르겠다고 하면 '정보 부족'으로 표시한다.
- 세부 기질 점수 = 문항 평균을 0~100으로 환산. 축 점수 = 세부 기질 3개의 평균.
- 50 이상이면 앞 글자(E, S, F, J), 미만이면 뒤 글자(I, N, T, P).
- 50에서 20 이상 떨어지면 '뚜렷함', 8 이상이면 '약간', 그 안이면 '균형에 가까움'.
- 자라는 힘: 65 이상 '탄탄함', 40~64 '고르게 자라는 중', 40 미만 '지금 자라는 중'.
- 응답 일관성: 같은 세부 기질 안에서 정방향 문항 평균과 역방향 문항(뒤집은 값) 평균의 차이. 0.9 미만 높음, 1.5 미만 보통, 그 이상 낮음. 20문항 넘게 모두 같은 값이면 낮음.
- 또래 비교(백분위)는 아직 없다. 점수는 아이 안의 경향이다.

## 3. 화면 흐름

화면 주소는 `#` 뒤 이름으로 정한다. 아래 메뉴는 4칸이다: 홈, 무료 결과, 리포트, 대화.

| 화면 | 주소 | 내용 |
|---|---|---|
| 홈 | `#home` | 아이 이름·연령·답하는 사람 입력, 무료 간이검사와 정밀검사 상품 카드, 샘플 보기 |
| 검사 | (주소 없음) | 한 문항씩 답하기. 아래 메뉴 대신 '이전 문항', '나중에 하기' |
| 무료 결과 | `#quick-result` | 간이 결과, 정밀검사에서 열리는 잠긴 항목(기질 결과·성격 결과로 구분), 결제 유도 |
| 결제 | (주소 없음) | 이용권 설명과 결제 버튼. 아래 메뉴 숨김 |
| 리포트 | `#report` | 정밀 리포트. 공통 머리 + '기질' / '성격(자라는 힘)' 탭 + 공통 아래 영역. [세부 기획서](content/report.md) |
| 대화 | `#coach` | 상황별 AI 대화(시제품은 목업 답변) |
| 문항과 정책 | `#blueprint` | 내부 검토용. 두 검사 비교표, 상품 정책, 채점 규칙, 전체 문항 |

- 리포트와 대화는 정밀검사 66문항을 모두 답해야 열린다. 다 하지 않았으면 "아직 결과가 없습니다" 안내가 나온다.
- 정밀검사를 다 했지만 이용권을 산 적이 없으면 결제 화면이 나온다.
- 리포트 안의 탭 전환은 주소와 아래 메뉴 켜짐 표시를 바꾸지 않는다.

## 4. 이용권과 결제

| 항목 | 값 |
|---|---|
| 가격 | 5,900원, 1회 결제. 자동 결제 없음 |
| 기간 | 60일(화면 표기 '2달') |
| 포함 | 정밀 리포트, 상황별 AI 대화, 기간 중 다시 검사하기 1회 |
| AI 대화 한도 | 30일마다 30회, 하루 5회, 한 상황당 이어 묻기 3회, 입력 500자 |
| 횟수에서 빼는 것 | 자주 묻는 상황 6가지(미리 써 둔 답) |
| 기간이 끝나면 | 리포트(두 탭 모두)는 계속 볼 수 있음. AI 대화와 다시 검사하기는 잠김. 다시 결제하면 60일이 새로 열림 |
| 안전 | 자해·학대가 의심되는 문장은 AI에 보내지 않고 상담 전화(109, 112) 안내 |

시제품이라 실제 결제는 연결되어 있지 않다. 결제 버튼을 누르면 바로 이용권이 열린다.
값은 `index.html` 의 `LIM`, `buyPass`, `DAY` 에 있다.

## 5. 저장

브라우저 `localStorage` 의 `aigyeol` 키에 JSON 하나로 저장한다. 서버 저장은 없다.

| 필드 | 뜻 |
|---|---|
| `ans` | 문항 id → 응답(1~5, 0은 '잘 모르겠다') |
| `name`, `age`, `who` | 아이 이름, 연령, 답하는 사람 |
| `date` | 마지막 응답일 |
| `qd` | 간이검사 완료 표시 |
| `pass` | 이용권 `{start, end, retest, n}` |
| `use` | AI 대화 사용량 `{mk, mn, dk, dn}` |
| `prev` | 다시 검사하기 전 결과 `{code, date}` |

리포트에서 어느 탭을 보고 있었는지는 저장하지 않는다. 리포트를 새로 열면 늘 기질 탭부터 보인다.
