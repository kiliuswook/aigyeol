# 결과 화면(정밀 리포트) 세부 기획서

- 최종 수정일: 2026-11-15
- 버전: 웹 시제품(별도 버전 번호 없음)
- 상위 문서: [전체 기획서](../GDD.md)
- 구현: `index.html` 의 `V.report`(화면), `setRtab`(탭 전환), `cmpHTML`·`compareGrow`·`CMP`(이전 검사와 비교), 스타일 `.rtabs` / `.rtab` / `.rpanel` / `.cmp`

## 열리는 조건

- 주소 `#report`, 아래 메뉴 '리포트' 칸.
- 정밀검사 66문항을 모두 답해야 열린다. 아니면 "아직 정밀검사 결과가 없습니다" 안내와 검사 시작·샘플 버튼이 나온다.
- 이용권을 산 적이 없으면 결제 화면이 대신 나온다.
- 이용권이 끝나도 리포트(두 탭 모두)는 계속 볼 수 있다.

## 화면 구성(위에서 아래로)

### 0. 양육자별 결과 (맨 위)

- 양육자 칩을 누르면 그 양육자의 리포트로 바뀐다. 아직 시작하지 않은 양육자는 `+ 이름` 칩으로 정밀검사를 시작한다. [양육자별 검사 세부 기획서](../systems/caregivers.md)

### 1. 공통 머리 (탭과 상관없이 늘 보임)

- 배너 그림
- 머리글: '내 아이의 MBTI · 정밀검사', 제목 '정밀검사 결과 보고서', 부제 '기질 결과와 성격(자라는 힘) 결과'
- 정보 칸: 이름, 연령, 평가자, 검사일(다시 검사했으면 이전 유형 코드. 예전 형식 기록이어도 같게 보임), 문항(66문항 · 5점 척도), 응답 일관성과 '잘 모르겠다' 개수(0문항이어도 표시)

### 2. 탭

| 탭 | 표시 이름 | 처음 상태 |
|---|---|---|
| 기질 | 기질 | 처음 열면 이 탭이 선택됨 |
| 성격 | 성격(자라는 힘) | |
| 양육자 비교 | 양육자 비교 | |
| 달라진 점 | 달라진 점 | |

- **탭 이름은 확정 전 임시 이름이다.** 바꾸면 이 문서와 홈·간이 결과·결제·문항과 정책 화면 문구를 함께 고친다.
- 탭 전환은 화면 안의 상태로만 처리한다. 주소(`#report`)와 아래 메뉴 켜짐 표시는 바뀌지 않고, 스크롤 위치도 그대로다.
- 리포트에 새로 들어올 때(아래 메뉴, 샘플 리포트, 검사 완료, 결제 직후)는 기질 탭으로 돌아간다. 같은 화면에서 '이용권 만료시키기' 같은 시제품 도구를 눌러 화면이 다시 그려질 때는 보던 탭을 유지한다.
- 모양: 크레용 꼬리표 틀 네 칸을 두 줄(2칸씩)에 같은 폭으로 둔다. 선택된 탭은 하늘색 크레용 버튼 틀. 손글씨 글꼴 19px, 폭 420px 이하에서 17px. 폭 360px 에서도 글자가 잘리지 않는다.
- 접근성: 탭 목록·탭·탭 패널 역할과 선택 상태를 화면 읽기 프로그램에 알린다.

### 3. 기질 탭

1. 기질 유형 카드: 네 글자 코드, 유형 캐릭터, 별명, 한 줄 풀이
2. 한눈에 보는 기질 프로필: 4축 막대, 균형 구간(40~60) 안내
3. 4축 카드(축마다 1장): 축 이름, 성향과 강도(뚜렷함/약간/균형에 가까움), 막대, 요약, 태그, 펼치면 상세 설명·세부 기질 3개·이렇게 말해 보세요/피할 말
4. 강점과 살펴볼 점
5. 아이에게 잘 통하는 말

자라는 힘은 이 탭에 없다.

### 4. 성격(자라는 힘) 탭

- 안내: 기질은 타고나지만 끈기, 스스로 힘, 함께 힘은 경험으로 자란다. 나이가 어릴수록 낮게 나오는 것이 자연스럽다.
- 끈기, 스스로 힘, 함께 힘 각각: 0~100 게이지와 점수, 단계(지금 자라는 중 / 고르게 자라는 중 / 탄탄함)와 한 줄 설명, 펼치면 상세 설명
- 한 척도의 문항을 대부분 '잘 모르겠다'로 답해 점수가 없으면 "판단하지 않았습니다" 안내만 보인다.
- 단계 기준: 65 이상 탄탄함, 40~64 고르게 자라는 중, 40 미만 지금 자라는 중. 문구는 `index.html` 의 `GR[].lv`.

- 맨 아래에 **이전 검사와 비교** 카드가 있다(아래 규칙).

기질 내용은 이 탭에 없다.

#### 이전 검사와 비교

다시 검사하기 전에 남긴 이전 기록(저장 항목은 [저장 세부 기획서](../systems/save.md))과 지금 결과를 비교한다. 구현은 `index.html` 의 `CMP`(기준 값), `compareGrow`(판정), `cmpHTML`(화면).

카드 머리: '이전 검사와 비교', 제목 '지난번과 달라진 점', 이전 검사일과 이전 평가자(샘플 기록이면 '샘플 예시 기록').

| 상황 | 보이는 것 |
|---|---|
| 이전 기록이 없음(다시 검사한 적 없음, 전부 지우기 뒤) | **비교 기록 없음** 과 짧은 설명 |
| 이 기능 전에 다시 검사해 유형 코드와 날짜만 남은 기록 | **비교 기록 없음** (점수가 없으므로) |
| 이전 평가자와 지금 평가자가 다름 | 숫자 없이 "평가자가 달라 직접 비교하기 어렵습니다"와 두 평가자 이름 |
| 평가자가 같음 | 힘 3가지마다 한 줄: 이름, "이전 ○ → 지금 ○", 판정 꼬리표 |

힘마다 판정:

- 이전이나 이번 검사에서 그 힘의 '잘 모르겠다'가 문항의 **절반 이상**(6문항 중 3개 이상)이면 그 힘은 비교하지 않고 "(이전 검사 / 이번 검사 / 이전과 이번 검사 모두)에서 '잘 모르겠다'가 절반 이상이라 비교하지 않았습니다"를 보인다. 나머지 힘은 그대로 비교한다.
- 점수 차이(지금 − 이전)의 크기가 **12.5 미만**이면 '비슷함'. 점수가 정수이므로 실제로는 12 이하가 비슷함, 13 이상 오르면 '자랐음', 13 이상 내리면 '낮아졌음'.
- 12.5는 6문항 척도에서 답 세 칸에 해당하는 폭이다(답 한 칸 = 100 ÷ 4 ÷ 6 ≈ 4.2점).
- 꼬리표 색: 비슷함 `c2`, 자랐음 `c4`, 낮아졌음 `c1` 점.
- 카드 아래 안내: 작은 차이는 '비슷함'으로 본다, 순위나 진단이 아니라 같은 평가자가 본 변화의 방향이다.

> **확정 전 임시 기준, 감수 필요.** '비슷함' 폭 12.5, '잘 모르겠다' 비교 제외 기준 절반(0.5)은 `index.html` 의 `CMP` 한곳에 있다. 바꾸면 이 문서와 [저장 세부 기획서](../systems/save.md)를 함께 고친다.

샘플 리포트: '샘플 리포트 보기'를 누를 때 이전 기록이 없으면 비교 화면 확인용 샘플 이전 기록을 함께 넣는다. 같은 평가자, 끈기는 20점 낮게(→ 자랐음), 스스로 힘은 같게(→ 비슷함), 함께 힘은 '잘 모르겠다' 4개(→ 비교 제외). 이미 이전 기록이 있으면 건드리지 않는다.

### 4-2. 양육자 비교 탭, 달라진 점 탭

[양육자별 검사 · 다시 검사하기 세부 기획서](../systems/caregivers.md)에 있다.

### 5. 공통 아래 영역 (탭과 상관없이 늘 보임)

1. 결과를 읽을 때 안내(평가자 시선, 응답 일관성이 낮을 때 재검사 권유, 의학적 진단이 아님)
2. AI 대화 안내와 '상황별 대화 열기' 버튼
3. 이용권 막대(남은 기간·대화 사용량, 끝났으면 다시 결제 버튼)
4. '다시 검사하기'(이용권 기간 중이고 아직 쓰지 않았을 때만, 이용권당 1회), '문항과 정책 보기'. 누르면 이전 기록을 남기고 답을 지운 뒤 66문항을 다시 시작한다([저장 세부 기획서](../systems/save.md))
5. 시제품 확인용 도구(이용권 만료시키기, 오늘 한도 채우기, 전부 지우기). 전부 지우기는 이전 기록도 지운다

## 관련 문구(다른 화면)

정밀 리포트가 기질 결과와 성격 결과로 나뉜다는 것을 아래 화면에서도 같은 말로 적는다.

- 홈 정밀검사 카드: "66문항 정밀 리포트: 기질 결과(4축, 세부 기질 12)와 성격 결과(자라는 힘 3)"
- 간이 결과의 잠긴 항목: "기질 결과: 세부 기질 12가지", "성격 결과: 자라는 힘 3가지"
- 결제 화면: 정밀 리포트 = 기질 결과(4축, 세부 기질 12가지, 강점과 살펴볼 점, 잘 통하는 말)와 성격 결과(자라는 힘 3가지)
- 문항과 정책: 비교표의 '보여 주는 것'을 기질 결과 / 성격 결과 / 공통으로 나눔, 자라는 힘 문항표 제목은 '성격(자라는 힘)'
