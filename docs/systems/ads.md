# 광고(AdMob) 수익 모델

2026-11-20 원더 결정: 검사마다 결제하던 방식을 없애고 광고로 운영한다.

| 광고 | 언제 | 코드 |
|---|---|---|
| 보상형 | 검사를 시작할 때 1번(첫 검사, 다른 양육자, 다시 검사하기 모두). 끝까지 보면 검사가 열리고, 중간에 닫으면 열리지 않는다. 보여 줄 광고가 없으면(인터넷 끊김, 재고 없음, 광고 미지원) 검사를 막지 않고 그냥 연다. | `lib/ui/pay.dart` → `ads.showRewarded()` |
| 배너 | 아래 메뉴(홈·기질·성격·성장 발달·오늘·더보기) 바로 위, 적응형 앵커 배너 | `BannerBox` (`lib/main.dart` Shell) |
| 앱 오프닝 | 페이지가 바뀔 때(화면 이동, 아래 메뉴 이동). 마지막 전면 광고(앱 오프닝·보상형)에서 3분이 지났을 때만. 앱을 켠 뒤 첫 3분은 나오지 않는다. 팝업창은 페이지로 치지 않는다. | `AdRouteObserver`, `ads.onPageChange` |

- 광고 ID: `app/lib/ads.dart` 의 `AdIds` 한곳. 디버그 빌드(`flutter run`)는 구글 테스트 광고 ID, 릴리스 빌드만 실제 ID.
- 앱 ID: 안드로이드 `android/app/src/main/AndroidManifest.xml`, iOS `ios/Runner/Info.plist`(`GADApplicationIdentifier`, `SKAdNetworkItems`).
- 동의: 시작할 때 UMP 로 유럽·영국·스위스 동의 창(AdMob → 개인 정보 보호 및 메시지에서 자동 생성된 메시지). 더보기에 '광고 개인정보 설정'(필요한 지역에서만 보임).
- 광고 수위 PG 까지, 아동 대상 아님(부모용 앱).
- iOS 추적 허용(ATT) 요청은 하지 않는다. 맞춤 광고 대신 일반 광고가 나간다.
- 웹(루트 index.html, new/)은 광고 없음. 검사 무료.
