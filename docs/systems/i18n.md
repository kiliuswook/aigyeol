# 다국어(화면 언어)

- 최종 수정일: 2026-11-21
- 2026-11-21 원더: "이앱 글로벌로 배포하고싶어. 다국어 지원 기능넣어죠", "냠냠미로가 지원하는 언어 모두 넣어줘"
- 언어: 한국어(원문) · English · 日本語 · 中文(简体) · Español · Tiếng Việt (냠냠미로 플루터판과 같은 6개)
- 영어판 앱 이름: **My Child's MBTI** (2026-11-21 원더 결정)

## 고르는 방법
- 처음에는 휴대폰 언어를 따른다. 지원하지 않는 언어면 영어.
- 더보기 > 언어(Language)에서 바꾼다. "휴대폰 언어 따르기"로 되돌릴 수 있다. 고른 값은 SharedPreferences `childmbti_lang`.
- 바꾸면 문항·오늘 탭 데이터를 다시 읽고 앱 전체를 다시 그린다. 알림 문구도 다시 건다.

## 파일
| 무엇 | 어디 |
|---|---|
| 언어 목록·`tr()`·언어 저장 | `app/lib/i18n.dart` (`kLangs`) |
| 화면 문구 번역 | `app/assets/i18n/<언어>.json` — `{ "한국어 원문": "번역" }` |
| 66문항·유형 풀이·별명 | `app/assets/data/content.<언어>.json` (구조는 `content.json`과 같음) |
| 오늘 탭(미션·상황 카드·약속 안내)·형제 궁합 | `app/assets/data/daily.<언어>.json` |

## 코드 규칙
- 화면에 보이는 한국어는 `tr('원문')`으로 감싼다. 값은 `tr('{0}의 리포트', [nm])`. 원문이 곧 키라서 원문을 고치면 번역 파일의 키도 같이 고쳐야 한다(없으면 한국어가 그대로 보인다).
- 조사 함수(`ga`, `eun`, `ga2`)는 한국어가 아니면 빈 글자를 돌려준다.
- 저장 값은 한국어 그대로 둔다: 양육자 이름('엄마' 등, 기록의 키·링크·통계에 쓰임), 나이('만 5세'). 화면에 보일 때만 `cg()`, `ageTx()`로 바꾼다.
- 카카오톡 공유 버튼은 한국어일 때만. 다른 언어는 휴대폰 공유 창.
- 날짜·시각 고르기 창은 `MaterialApp.locale`로 앱 언어를 따른다.

## 언어별 주의
- 목록 이어 붙이기는 `listSep`(일본어·중국어 `、`, 나머지 `, `).
- 유형 한 줄 풀이: `tr('{0}입니다.', [특징들])` — 영어 "A child who {0}.", 스페인어 "Un peque que {0}.", 베트남어 "Một đứa trẻ {0}.", 일본어 "{0}です。", 중국어 "是一个{0}。". 리듬/자유(J/P) 특징은 "and …/y …/và …"로 시작한다.
- 문항·상황 예문의 '엄마'는 각 언어의 엄마 번역(Mom·ママ·妈妈·Mamá·Mẹ)과 똑같이 써야 리포트에서 아빠·할머니로 바뀐다.
- 오늘 탭 약속 안내의 `when`은 화면 번역 '3일 전'·'전날 저녁'·'당일 아침'과 글자가 같아야 순서대로 정렬된다.
- 샘플 아이 이름은 `tr('콩이')`(Kongi·コンイ·豆豆).
- 제목 글꼴 개구(Gaegu)에는 á·ñ·ơ 같은 글자가 없어 스페인어·베트남어 제목은 Patrick Hand(OFL, `app/assets/fonts/PatrickHand-*`)로 쓴다. 일본어·중국어는 휴대폰·웹 기본 글꼴로 대신 그린다.
- 긴 리포트 탭 이름은 띄어쓰기에서 두 줄로 나누고(`_twoLine`), 막대 양끝 이름은 한국어가 아니면 막대 위에 둔다(`axisBar`).

## 중국어 번체(zh-Hant, 2026-11-24)
- 대만·홍콩·마카오 기기(또는 Hant 표기)는 `zh-Hant`, 나머지 중국어는 간체 `zh`(`deviceLang()`). 날짜 창 등은 `localeOf()` 로 `zh_Hant`.
- 파일은 간체판을 OpenCC `s2twp`(대만 어휘)로 바꾼 것: `assets/i18n/zh-Hant.json`, `assets/data/{content,daily,dev}.zh-Hant.json`. 간체를 고치면 다시 변환하고 `型別`→`類型` 처럼 잘못 바뀐 말을 확인한다. 원어민 감수 전.
- 스토어: `release/store-global/listings.json` 의 play `zh-TW`(+ `zh-HK` 같은 문구), appstore `zh-Hant`.

## 개인정보처리방침 언어판
- `privacy.html`(한국어, 한국 이용자용) + `privacy-{en,ja,zh,es,vi}.html`(해외 이용자용, GDPR 법적 근거·국외 이전·미국 주 법 권리 포함). 공통 모양 `assets/privacy.css`.
- `privacy.html` 은 기기 언어가 한국어가 아니면 그 언어판으로 넘긴다(`?hl=ko` 는 그대로). 스토어에 등록된 주소는 바꾸지 않아도 된다.
- 앱 안 링크는 `privacyUrl()`(ui/links.dart): 앱 언어에 맞는 판. 방침을 바꾸면 6개 파일을 함께 고친다.
