# 로그인·동기화 (Firebase)

2026-11-17 원더 결정: Firebase 메일 인증으로 동기화. 로그인은 **선택**(안 해도 이 폰에서 모두 쓸 수 있음).

## 흐름
1. 홈의 "기록 지키기" 카드 → 계정 화면에서 메일·비밀번호로 가입 → 인증 메일 발송.
2. 메일의 링크를 누르고 "인증했어요" → 서버 기록과 이 폰 기록을 합쳐(`Store.mergeFrom`) 다시 올림.
3. 그 뒤로는 기록이 바뀔 때마다 3초 뒤 자동 저장. 다른 폰에서 같은 메일로 로그인하면 합쳐짐.
4. 로그아웃해도 폰 기록은 남음. 계정 삭제는 서버 문서 + 계정 삭제(폰 기록은 남음).

## 서버 자료
- Firestore `users/{uid}`: `{json: Store.toJson() 문자열, at: 서버 시각, v: 2}`. 보안 규칙 `firestore.rules`(본인만, 쓰기는 메일 인증 후).
- 합치기 규칙: 같은 아이(key)는 양육자별로 더 최근에 바뀐 기록(`Rec.t`, 없으면 날짜, 같으면 답이 많은 쪽). 결제 기록은 id 로 합침. 없는 아이는 추가.

## 플레이 정책
- 앱 안 계정 삭제: 홈 → 계정 관리 → 계정 삭제.
- 웹 삭제: https://childmbti.wonderwheel.co.kr/delete-account.html (메일·비밀번호로 바로 삭제). 플레이 콘솔 "데이터 삭제" 항목에 이 주소.
- 심사용 계정: 메일 인증을 마친 테스트 계정을 만들어 플레이 콘솔 "앱 액세스"에 적음(비밀번호는 저장소에 두지 않음).

## 배포
- 규칙: 저장소 루트에서 `npx firebase-tools deploy --only firestore:rules` (원더휠 계정으로 로그인한 PC).
