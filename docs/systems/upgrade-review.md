# 스토어 업데이트 알림 · 평가 요청 (2026-11-21, 1.2.0+6)

코드: `app/lib/upgrade.dart`, 연결은 `app/lib/main.dart`(인트로 뒤 3초에 한 번 확인, 리포트 탭 진입 시 평가), 더보기 > "앱 평가하기".

## 업데이트 알림
- 안드로이드: 구글 플레이 인앱 업데이트(`in_app_update`).
  - 기본은 유연 업데이트: 새 버전을 뒤에서 받아 두고, 다 받으면 아래에 "새 버전을 받았어요 · 다시 시작" 한 줄.
  - 꼭 올려야 하는 버전은 Play Console 출시 때 **업데이트 우선순위 4~5** 로 올리면 바로 업데이트 화면(앱 사용 전 업데이트).
    우선순위는 콘솔 화면에서 못 바꾸고 API(edits.tracks 의 releases[].inAppUpdatePriority)로만 정한다.
  - 플레이에서 설치한 앱에서만 동작한다(직접 설치한 APK·디버그 빌드는 "업데이트 없음").
- iOS: 애플은 인앱 업데이트 API 가 없다. 앱스토어 조회(itunes.apple.com/lookup, bundleId)로 새 버전을 알면
  "새 버전이 나왔어요 [나중에] [업데이트]" 창, 같은 버전은 3일에 한 번만. 정식 출시 전(TestFlight 만)에는 조회 결과가 없어 뜨지 않는다.
- 휴대폰 자체의 자동 업데이트(플레이·앱스토어 설정)는 사용자가 켜는 것이라 앱이 바꿀 수 없다.

## 평가 요청
- OS 기본 평가 창(`in_app_review`). 검사를 마친 리포트를 **두 번째로 볼 때부터**, 90일에 한 번, 최대 3번.
- 광고가 떠 있으면 건너뛴다. "만족하세요?" 같은 먼저 묻기는 두지 않는다(좋은 평가만 고르는 것으로 보이면 플레이·애플 정책 위반).
- 창이 실제로 뜰지는 OS 가 정한다(iOS 는 1년 3번 제한, 플레이는 할당량). TestFlight·내부 테스트에서는 안 뜨거나 제출이 안 될 수 있다.
- 더보기 > "앱 평가하기" 는 항상 스토어 평가 화면을 연다.
