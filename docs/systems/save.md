# 저장 세부 기획서

- 최종 수정일: 2026-11-15
- 버전: 웹 시제품(별도 버전 번호 없음)
- 상위 문서: [전체 기획서](../GDD.md)
- 구현: `index.html` 의 `st`(상태), `save`, `snapshot`(이전 기록 만들기), 클릭 처리의 `data-retest` / `data-reset`

## 저장 위치

브라우저 `localStorage` 의 `aigyeol` 키에 JSON 하나로 저장한다. 서버 저장은 없다. 같은 브라우저에서만 이어진다.

## 저장 항목

| 필드 | 뜻 |
|---|---|
| `ans` | 문항 id → 응답(1~5, 0은 '잘 모르겠다') |
| `name`, `age`, `who` | 아이 이름, 연령, 지금 고른 양육자(평가자). `ans`·`date`·`qd`·`prev` 는 이 양육자의 기록 |
| `date` | 마지막 응답일(`YYYY.MM.DD`) |
| `qd` | 간이검사 완료 표시 |
| `pass` | 이용권 `{start, end, retest, n}`. `retest` 는 이번 이용권에서 다시 검사한 횟수(최대 1) |
| `use` | AI 대화 사용량 `{mk, mn, dk, dn}` |
| `prev` | 다시 검사하기 전 결과(이전 기록). 아래 |
| `cgs` | 다른 양육자들의 기록 `{이름: {ans, date, qd, prev}}`. 홈의 '답하는 사람'이나 리포트 위 양육자 칩으로 바꾸면 지금 기록을 여기에 넣고 고른 사람 기록을 꺼낸다(`setWho`). 답도 이전 기록도 없는 양육자는 넣지 않는다. [양육자별 검사](caregivers.md) |

리포트에서 어느 탭을 보고 있었는지는 저장하지 않는다.

### 이전 기록 `prev`

| 필드 | 뜻 | 생긴 때 |
|---|---|---|
| `code` | 이전 네 글자 유형 코드 | 처음부터 |
| `date` | 이전 검사일 | 처음부터 |
| `who` | 이전 평가자 | 비교 기능부터 |
| `ax` | 기질 4축 점수 `{A, B, C, D}` (0~100) | 비교 기능부터 |
| `gr` | 자라는 힘 점수 `{G1 끈기, G2 스스로 힘, G3 함께 힘}` (0~100, 모두 '잘 모르겠다'면 `null`) | 비교 기능부터 |
| `unk` | 자라는 힘별 '잘 모르겠다' 개수 `{G1, G2, G3}` (각 0~6) | 비교 기능부터 |
| `sample` | 샘플 리포트가 넣은 예시 기록이면 `1` | 비교 기능부터 |
| `sub` | 세부 기질 점수 `{A:[3개], B, C, D}` | 양육자·재검사 기능부터 |
| `ans` | 문항별 답 전체(다시 검사하기 직전 답) | 양육자·재검사 기능부터 |

- 저장 위치(`prev`)는 그대로 두고 항목만 늘렸다. 기존 사용자 데이터를 옮기지 않는다.
- 예전 형식 `{code, date}` 기록은 그대로 읽는다. 리포트 머리의 이전 유형 코드는 보이고, 성격 탭 비교는 점수가 없으므로 '비교 기록 없음'이다.
- 기질 4축·세부 기질 점수와 문항별 답은 '달라진 점' 탭과 재검사 화면에서 쓴다. 이 항목이 없는 예전 기록은 있는 항목만 보인다.

## 다시 검사하기

- 리포트 아래 '다시 검사하기' 버튼. 이용권 기간 중이고 이번 이용권에서 아직 쓰지 않았을 때만 보이고 동작한다(이용권당 1회). 다시 결제하면 새 이용권에서 다시 1회.
- 누르면 순서대로:
  1. 지금 답으로 채점한 결과를 `prev` 에 남긴다(위 표의 항목 전부). 이전에 남은 `prev` 는 덮어쓴다.
  2. `pass.retest` 를 1 올린다.
  3. 답(`ans`)과 간이검사 완료 표시(`qd`)를 지운다.
  4. 66문항 정밀검사를 처음부터 시작한다.
- 평가자는 지우지 않는다. 이전 기록은 양육자별로 남으므로, 다시 검사 도중 홈에서 '답하는 사람'을 바꾸면 다른 양육자의 기록으로 바뀌고 다시 검사 중이던 기록은 그 양육자에게 그대로 남는다.
- 이용권당 1회는 양육자 모두 합친 횟수다(가정).
- 다시 검사하는 동안 선택지 옆에 지난번 내 답과 다른 양육자의 답이 보인다([양육자별 검사](caregivers.md#다시-검사하기-화면)).
- 비교 규칙과 판정 기준은 [결과 화면 세부 기획서](../content/report.md#이전-검사와-비교).

## 전부 지우기

- 리포트·대화 화면의 '시제품 확인용 도구' 안 '전부 지우고 처음부터'.
- 답, 간이검사 완료 표시, 이용권, AI 대화 사용량, **이전 기록(`prev`)**, **다른 양육자 기록(`cgs`)**, 진행 중인 대화를 지우고 홈으로 간다. 이름·연령·평가자·검사일은 남는다.
- 지운 뒤 다시 정밀검사를 마치면 성격 탭 비교는 '비교 기록 없음'이다.

## 샘플 리포트

- '샘플 리포트 보기'는 지금 답을 샘플 답으로 덮어쓴다.
- 이전 기록이 없을 때만 비교 화면 확인용 샘플 이전 기록(`sample: 1`)을 넣고, 정밀검사를 마친 다른 양육자가 없으면 샘플 양육자 한 명을 넣는다. 내용은 [양육자별 검사](caregivers.md#샘플-리포트). 이미 있으면 그대로 둔다.

## 판정 기준 값 (확정 전 임시 기준, 감수 필요)

`index.html` 의 `CMP` 한곳에 있다.

| 값 | 현재 | 뜻 |
|---|---|---|
| `CMP.same` | 12.5 | 점수 차이 크기가 이보다 작으면 '비슷함'(답 세 칸 폭) |
| `CMP.unkHalf` | 0.5 | 한 힘에서 '잘 모르겠다'가 이 비율 이상(6문항 중 3개 이상)이면 비교 제외 |
| `CMP.sub` | 25 | 세부 기질 점수 차가 이 이상이면 '달라진 세부 기질' |
| `CMP.gap` | 2 | 같은 문항 답이 이 칸 수 이상 다르면 '크게 바뀐 문항' / '답이 크게 갈린 문항' |
