# 자체 도메인 세부 기획서

- 최종 수정일: 2026-11-16
- 상위 문서: [전체 기획서](../GDD.md), [결제·공유](pay-share.md)

## 왜

2026-11-16 원더: 공유하기·링크 배포에 `kiliuswook.github.io` 대신 자체 도메인 주소를 쓴다(주파수처럼).

## 한곳에서 바꾸기

```
python3 tools/set_domain.py <도메인>     # 예: mbti.example.com
python3 tools/set_domain.py --github     # 원래 주소로 되돌리기
```

바뀌는 곳: `index.html` 의 `SITE`(공유·초대·결과 링크, 카카오 공유 카드 이미지), 링크 미리보기 og 태그, 저장소 맨 위 `CNAME` 파일.
개인정보처리방침은 `privacy.html` 상대 주소로 연결되어 따로 바꿀 것이 없다.

## 순서

1. 도메인 정하기(원더). 하위 도메인 권장(예: `mbti.<원더 도메인>`).
2. DNS 레코드 추가(원더, 도메인 업체 관리 화면)
   - 하위 도메인: `CNAME` 레코드, 이름 `mbti`, 값 `kiliuswook.github.io`
   - 맨 앞 도메인(apex)을 쓸 때: `A` 레코드 4개 `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. `tools/set_domain.py <도메인>` 실행 후 main 에 푸시. GitHub 저장소 Settings > Pages 의 Custom domain 에 같은 도메인이 들어갔는지 확인하고, 인증서가 나오면 Enforce HTTPS 를 켠다.
4. 카카오 개발자 콘솔 > 앱 > 플랫폼 > Web 사이트 도메인에 `https://<도메인>` 등록(카카오 공유 링크가 이 도메인으로만 열림).
5. 구글 플레이 등록 정보·개인정보처리방침 주소를 새 도메인으로 바꾼다(`https://<도메인>/privacy.html`).

## 바뀐 뒤

- 예전 `kiliuswook.github.io/aigyeol/...` 링크는 GitHub 가 새 도메인으로 넘겨 준다. `#` 뒤 값은 브라우저가 그대로 들고 가므로 이미 보낸 초대·결과 링크도 열린다.
- 브라우저 저장소는 주소마다 따로라, 예전 주소에서 한 검사 기록은 새 주소에서 보이지 않는다. 시제품 사용자는 예전 주소에서 '기록 파일 저장' 뒤 새 주소에서 불러오면 된다.
- 안드로이드 앱 링크(App Links)도 이 도메인 기준으로 만든다(`/.well-known/assetlinks.json`).
