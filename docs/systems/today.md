# 오늘 탭: 부모 칭찬 스티커 미션 · 약속·일정 · 상황 카드

- 최종 수정일: 2026-11-20 (원더 요청: 지속 사용 콘텐츠 아이디어 1·2와 상황 카드 도감 적용, 보상은 따로 두지 않음)
- 구현: `app/lib/daily.dart`(데이터·기록), `app/lib/notify.dart`(예약 알림), `app/lib/ui/today.dart`(화면)
- 문장: `app/assets/data/daily.json`. 모두 미리 쓴 글이라 AI 호출 비용이 없다. 전문가 감수 전 초안.
- 아이디어 문서: https://claude.ai/artifact/5wQHwWtApJZS31CLhwwFct

## 자리

아래 메뉴는 홈 · 오늘 · 리포트 · 더보기 4칸이다. 코드의 탭 번호는 예전 그대로(0 홈, 1 리포트, 2 더보기)이고 오늘이 3번이다.
오늘 탭 위 칩으로 세 칸을 오간다: 오늘의 미션 / 약속·일정 / 상황 카드. 아이가 둘 이상이면 아이 칩도 보인다.

## 오늘의 미션 (부모 칭찬 스티커)

- 하루 한 장. 아이의 네 글자 유형 극(E, I, S, N, F, T, J, P)마다 8개, 검사 전 공통(X) 6개.
- 고르는 법: 날짜마다 아이의 네 극을 돌아가며, 그 극 목록에서 하나. 아이마다 시작점이 다르다. '다른 미션'을 누르면 다음 것.
- '해 봤어요' → 아이 반응(잘 통했어요 / 그냥 그랬어요 / 안 통했어요) + 한 줄 메모(선택) → 휴대폰을 아이에게 건네 아이가 스티커(16유형 캐릭터 6개 중 하나)를 골라 붙인다.
- 스티커판: 이번 주 7칸, 연속 실천 일수, 이번 달 스티커 수. 놓친 날 벌점 없음. 별도 보상은 두지 않는다(2026-11-20 원더).
- '잘 통한 말': 잘 통했어요를 고르거나 메모를 남긴 날 모음.

## 약속·일정

- 약속(아이와 한 약속)과 일정 두 가지. 내용, 날짜(오늘·내일·모레·다른 날), 시각(선택). 자주 쓰는 내용 10개를 칩으로.
- 열어 보면 '미리 알려 주기': 아이의 극 가운데 J, P, S, N, E, I 에 맞춘 문장을 3일 전 · 전날 저녁 · 당일 아침 순서로 보여 준다. 검사 전은 리듬형(J) 기준.
- 약속을 지키면 아이가 스티커를 붙여 준다(스티커 수에 더함). 일정은 '다녀왔어요'만.

## 상황 카드 도감

- 24개 상황, 분류 일상·감정·사회·변화·습관. 상황마다 기준 축 하나(A~D)와 그 양쪽 극의 '이렇게 말해 보세요 / 이렇게 해 보세요 / 이런 말은 피해 주세요'.
- 검사를 마친 아이는 자기 극이 먼저(분홍 칸), 반대 극은 참고로 아래에.

## 알림

- 이 휴대폰 안의 예약 알림(flutter_local_notifications). 서버 없음. 웹은 알림 없음.
- 사용자가 '알림 받기'를 누를 때만 권한을 묻고 켠다. 아침 미션(기본 오전 9:00), 저녁 확인(기본 오후 8:30, 그날 해 봤으면 생략), 약속·일정(3일 전·전날 오후 7시, 당일 오전 8시. 3일 전은 J·S·I 아이만).
- 앱을 켤 때와 기록이 바뀔 때 모두 지우고 앞으로 7일 치를 다시 건다(iOS 예약 64개 한도 아래로 60개까지).
- 안드로이드: POST_NOTIFICATIONS, RECEIVE_BOOT_COMPLETED 권한, 예약 알림 receiver 2개, core library desugaring. iOS: AppDelegate 에서 알림 delegate.

## 기록

- SharedPreferences 'childmbti_daily' 에 아이 id 별로. 계정 동기화(Firebase)와 기록 파일 백업에는 아직 넣지 않았다. 공동 양육자와 함께 쓰려면 동기화가 필요하다.

## 형제 궁합 리포트 (리포트의 '형제' 탭)

- 2026-11-20 원더 요청. 구현 `app/lib/ui/sibling.dart`, 문장 `daily.json` 의 `sib`.
- 아이가 둘 이상 등록되면 리포트 위 탭에 '형제'가 생긴다. 두 아이 모두 정밀검사를 마쳐야 열리고, 아니면 남은 아이를 알려 준다. 셋 이상이면 짝 칩으로 고른다.
- 축마다 세 경우(둘 다 앞 글자 hh, 둘 다 뒤 글자 ll, 서로 다름 mix) 문장 묶음 = 12묶음으로 16×16 조합을 모두 덮는다. 각 묶음: 잘 맞는 점, 부딪히는 점, 부모 팁, 놀이 2개, 연결 상황 카드.
- 요약: 두 캐릭터, 궁합 이름(같은 축 수 0~4: 정반대 짝꿍 · 다른 매력 형제 · 반반 닮은 형제 · 닮은꼴 형제 · 판박이 형제), 4축 같음·다름.
- 자세히 보기 3개: 잘 맞는 점과 함께할 놀이(같은 축부터 3개) / 자주 부딪히는 상황(다른 축부터 3개 + 상황 카드, '형제·자매가 다툴 때'는 늘 포함) / 아이마다 다르게 칭찬하기(극별 칭찬 한마디) + 공유하기(휴대폰 공유 창, 글+앱 주소).
- 만 8세 이상 아이가 있으면 '만 2~7세 기준' 안내. 둘을 견주는 말(더 좋다·나쁘다)은 쓰지 않는다.
