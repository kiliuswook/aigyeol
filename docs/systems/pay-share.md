## 원더의 최종 스펙(2026-11-16)

- API 음성·채팅 대화 콘텐츠 제거. 자녀 MBTI 검사만 연다.
- 검사마다 인앱결제. 첫 검사만 $1, 나머지는 $0.50(바뀔 수 있음).
- 자녀 등록: 다자녀는 따로 검사·관리. 자녀당 첫 검사만 $1, 양육자·재검사 등은 $0.50.
- 공유는 필수: 친구·가족 공유(카카오톡 필수)는 앱 다운로드로, 공동 양육자는 검사하기로 연결.
- 무료 12문항 검사는 없앰(같은 날 결정).

## 결제

| 검사 | 가격 | 결제 화면 이름 |
|---|---|---|
| 아이의 첫 정밀검사(누가 하든) | `PRICE.first` = $1 | 첫 정밀검사 |
| 같은 아이의 다른 양육자 검사 | `PRICE.more` = $0.50 | 양육자 추가 검사 |
| 다시 검사하기 | `PRICE.more` = $0.50 | 다시 검사하기 |

- 판정: 그 아이의 결제 기록(`buys`)이 하나라도 있거나 초대로 받은 아이(`ext`)면 $0.50, 아니면 $1.
- 형제 검사는 따로 값이 없다. 형제는 새 아이로 등록하므로 그 아이의 첫 검사 $1이다. (원더 예시의 "형제 검사 추가 0.5달러"와 다름. 원더 확인 대기)
- 결제는 검사를 시작하기 전에 한다. 결제하면 지금 양육자의 `paid` 가 켜지고 '나중에 하기' 뒤에도 다시 내지 않고 이어 한다.
- 시제품은 결제 버튼을 누르면 바로 열린다. 실제 앱: 구글 플레이 인앱 상품 2개(소모성) `PRICE.sku.first`, `PRICE.sku.more`. 화면 가격은 플레이가 주는 현지 통화 가격으로 바꾼다.

## 자녀

- 홈 '우리 아이' 카드의 아이 칩으로 바꾸고 '+ 아이 추가'로 늘린다. 리포트 위에도 아이가 둘 이상이면 아이 칩이 나온다.
- 아이마다 이름·연령·양육자 기록·이전 기록·결제 기록이 따로다.

## 공유

`SHARE` 한곳에 카카오 키, 웹 주소, 플레이 주소가 있다.

| 공유 | 링크 | 받은 사람이 보는 것 |
|---|---|---|
| 결과 카드(친구·가족) | `?t=ISTJ` | 친구네 아이 유형 카드 + '우리 아이 검사하기'(플레이 주소가 있으면 '앱 받기') |
| 앱 추천 | `?r=app` | 앱 소개 + 앱 받기 / 검사 시작 |
| 공동 양육자 초대 | `?i=...` | 초대장: 아이 이름·연령, '나는' 고르기, 가격, 검사 시작 |
| 결과 보내기(초대받은 사람 → 초대한 사람) | `?c=...` | 도착한 결과 + '합쳐서 비교 보기' |

- 결과 카드에는 아이 이름과 답을 싣지 않는다. 유형과 별명만.
- 초대 링크에는 아이 `key`, 이름, 연령, 보낸 사람, 받을 사람 역할, 첫 검사 결제 여부가 실린다. 결과 링크에는 그 위에 66문항 답(66글자)이 실린다. 링크를 받은 사람만 볼 수 있지만 누구에게 보내는지는 사용자가 정한다.
- 카카오톡: `SHARE.kakaoKey` 에 카카오 JavaScript 키를 넣으면 카카오 공유 카드(피드형, 이미지 `assets/share/유형.png`·`assets/og.png`)로 보낸다. 키가 없으면 휴대폰 공유 창, 그것도 없으면 링크 복사.
- 링크 미리보기용 og 태그와 `assets/og.png` 가 있다.

### 공동 양육자 초대와 결과 합치기

서버 없이 링크 두 번으로 푼다.

1. 엄마: 공유 > 공동 양육자 > 아빠 고르고 카카오톡으로 초대를 보낸다.
2. 아빠: 링크를 열면 같은 아이(`key`)가 아빠 휴대폰에 만들어지고 아빠 검사로 들어간다. 엄마가 첫 검사를 이미 결제했으면 $0.50.
3. 아빠: 검사를 마치면 리포트와 공유 화면에 '엄마에게 결과 보내기'가 나온다.
4. 엄마: 받은 결과 링크를 열면 같은 아이 기록의 아빠 결과로 합쳐지고 '양육자 비교' 탭이 열린다. 같은 아이가 없으면 새 아이로 추가한다.

한계: 결과는 보낸 때의 것이다. 아빠가 나중에 다시 검사하면 다시 보내야 한다. 초대 링크의 '첫 검사 결제됨'은 서버 확인이 아니어서 실제 앱에서는 서버 검증이 필요하다.

### 앱 다운로드 연결

- 지금은 웹 주소로 링크한다. 앱이 나오면 `SHARE.store` 에 플레이 주소를 넣는다.
- 실제 앱에서는 같은 링크를 Android App Links 로 앱에 연결하고, 앱이 없으면 플레이 설치로 보낸다(카카오 링크는 카카오 개발자 콘솔에 Android 패키지 이름 등록 필요). 설치 뒤 초대를 이어받으려면 Play Install Referrer 로 링크 값을 넘긴다.

## 기록과 구매 되살리기

지금은 모든 기록이 휴대폰 안(`localStorage`)에만 있다. 앱을 지우거나 휴대폰을 바꾸면 기록과 결제한 검사가 사라진다.

- **지금 들어간 것: 기록 파일.** 홈 '휴대폰을 바꾸거나 앱을 지울 때' > 기록 파일 저장 / 기록 불러오기. 모든 아이·양육자 기록과 결제 표시가 JSON 파일 하나로 옮겨진다.
- **소모성 상품의 한계.** 검사 1회 결제는 소모성 상품이라 구글 플레이가 '구매 복원'을 해 주지 않는다. 플레이에서 되살릴 수 있는 것은 비소모성 상품뿐이다.
- **제안(실제 앱):** 구글 로그인 + 작은 서버(예: Firebase)에 아이·결과·구매 토큰을 저장. 결제는 서버가 플레이 구매 토큰을 확인한 뒤 열고, 새 휴대폰에서 로그인하면 그대로 되살린다. 같은 서버로 공동 양육자 결과도 링크 없이 자동으로 합칠 수 있다. 개인정보처리방침에 서버 저장 항목을 추가해야 한다.
